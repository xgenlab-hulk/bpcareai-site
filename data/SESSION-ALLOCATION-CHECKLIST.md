## ⚠️ 注意事项

### 1. 避免批次冲突
**千万不要在两个Session中执行相同的批次ID！**

❌ **错误示例**:
- Session 1: `优化 batch-011`
- Session 2: `优化 batch-011` ← 重复了！

✅ **正确示例**:
- Session 1: `优化 batch-011`
- Session 2: `优化 batch-014` ← 不同的批次

### 2. 按顺序执行
在同一个Session中，**必须等前一个批次完成**后再执行下一个：

```bash
# Session 1执行流程
优化 batch-010
# 等待完成... ✅
优化 batch-011
# 等待完成... ✅
优化 batch-012
# 等待完成... ✅
优化 batch-013
# 全部完成 ✅
```

### 3. 遇到错误时
如果某个批次失败：
1. 记录失败的批次ID
2. 在该Session中跳过，继续执行下一个批次
3. 所有批次完成后，单独重新执行失败的批次
